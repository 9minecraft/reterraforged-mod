# Reterraforged Mod - The Best Terrain Generation

Reterraforged Mod is a mod with the goal of creating a new realistic terrain generator for Minecraft. While there are many mods that generate terrains, such as Biome O’Plenty, Terra 1-1, and Terrestria, TerraForged stands out by aiming to make Minecraft landscapes more realistic and immersive. The objective is to entice players to explore the newly generated world, and to achieve this, several enhancements have been made. These include improved rivers, erosion effects, and new decorations waiting to be discovered.

## What this build is

An unofficial rebuild of **Won-Ton, dags, racconman**'s original work, kept running on current releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Loader: Fabric, Forge, NeoForge, Neoforge.
